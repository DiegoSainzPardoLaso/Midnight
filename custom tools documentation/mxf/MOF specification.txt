==============================================================================================================================================================================================================================================
																									Midnight Object Format Specification
==============================================================================================================================================================================================================================================
Brief: Binary Format used to store mesh data. Way lighter, faster to load and more memory efficient 
	   leaving a smaller memory footprint than any other format.
==============================================================================================================================================================================================================================================
Note: The Joint ID influences are directly related to the Weights values. 
So [Weigh0] would be the value of the influence that the [joint0 with ID n] exercices over this vertex.
#--------------------#
| JoInf0 ---> Weigh0 |
| JoInf1 ---> Weigh1 |
| JoInf2 ---> Weigh2 |
| JoInf3 ---> Weigh3 |
#--------------------#
Note: 0, 1, 2, 3 are NOT the Joint IDs, nor the weight values
Note: When loading the joints, the root gets placed as the first joint of the list
Note: If the model is skinned, the mof file will also be responsible for having the skeleton stored inside.
Note: Quaternion order is X, Y, Z, W
Note: Multiple Objects per file are currently not supported
Note: Empty groups or vertex groups corresponding to deleted or removed bones might cause the MOF file to export the 'Wrong' data.

==============================================================================================================================================================================================================================================
																											    Legend
==============================================================================================================================================================================================================================================

 - PositX: Vertex or Joint position X
 - PositY: Vertex or Joint position Y
 - PositZ: Vertex or Joint position Z
 
 - VrColR: Red channel color assignated to this vertex
 - VrColG: Green channel color assignated to this vertex
 - VrColB: Blue channel color assignated to this vertex
 
 - NormlX: Vertex Normal X
 - NormlY: Vertex Normal Y
 - NormlZ: Vertex Normal Z
 
 - UCoord: U texture coordinate that this vertex has
 - VCoord: V texture coordinate that this vertex has
 
 
 - JoInfN: Joint N influence ID associated to WeighN. Meaning the Joint ID N that has X weight influence over this vertex while it's being animated
 - WeighN: Influence value that JoinfN exercises over this vertex
 
 - BonIdx: Bone index inside the skeleton hierarchy. It's related to JoInfn, so for example a skeleton with 1 bone, joint0 will have index 0, and if it has any influence over 
 - ParIdx: Bone parent index inside the skeleton hierarchy
 - CldCnt: Child count, number of childs that this joint has
 - CldIdA: Child Index array, the indices of this joint childs
