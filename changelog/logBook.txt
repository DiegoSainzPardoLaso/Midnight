---------------------------------------------------
| MOF/MAF Files                                     |
---------------------------------------------------

FBX, OBJ and DAE files have been discontinued, and are beign replaced by the MOF/MAF file standard.
MOF files hold mesh data like vertex positions, vertex colors, Normals UVs and if the mesh is skinned it also include
joint influence IDs and Weight Values related to the Joint influence id.
MAF files hold the actual animation that the model will use. so each frame has an array of n joints that hold the transform
of each joint per frame.

MOF -> Meshes and skeletons
MAF -> Animations
